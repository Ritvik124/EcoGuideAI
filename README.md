## Technologies Used

### Core Technologies

* **HTML5** — Frontend structure
* **CSS3** — Responsive user interface and styling
* **Vanilla JavaScript ES6** — Client-side interaction and API communication
* **Java 21** — Backend application logic
* **Jakarta Servlet 6.1** — HTTP request and response handling
* **JDBC** — Java–MySQL database connectivity
* **MySQL 8** — Persistent data storage
* **Apache Tomcat 11** — Java web application server
* **Maven** — Build and dependency management
* **Git** — Version control

### Current AI / Recommendation Technology

The current EcoGuide AI prototype uses an **explainable keyword-based recommendation approach implemented in Java**.

The system analyzes sustainability-related keywords, identifies the relevant category, generates a recommendation, and assigns a transparent prototype Eco Score.

This approach is intentionally simple and explainable for the current internship prototype.

### Planned AI Technologies

The project can be extended with modern Generative AI technologies, including:

* **IBM Granite** — Generative AI model for sustainability-focused responses
* **RAG (Retrieval-Augmented Generation)** — Retrieve trusted sustainability information before generating an answer
* **Agentic AI** — Enable an AI agent to reason about a user's sustainability request and perform appropriate actions
* **IBM watsonx / IBM BOB** — Potential enterprise AI platform/integration layer for future AI capabilities

These technologies are part of the **future AI enhancement**, unless explicitly implemented and configured in the deployed version.
