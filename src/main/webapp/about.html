ABOUT THE PROJECT

Helpful guidance, responsibly delivered.

EcoGuide AI is a B.Tech internship prototype that encourages sustainable everyday choices in support of SDG 12 and related goals.

Fairness

Recommendations are designed to be useful without discrimination.

Transparency

EcoGuide AI clearly identifies its responses as prototype recommendations.

Privacy

It stores only the question and answer needed to evaluate the feature—never unnecessary personal information.

Accuracy

It avoids unsupported claims. The Eco Score is an explainable prototype indicator, not a scientific measure.

Human Responsibility

AI suggestions support people; users make the final decisions.

Current Prototype AI Logic

User Question → Java Servlet → Keyword Analysis → generateAIResponse() → Recommendation

Future Generative AI Integration

User Question → Java Servlet → AI Service → IBM Granite / Generative AI → Sustainability Recommendation → Eco Score
